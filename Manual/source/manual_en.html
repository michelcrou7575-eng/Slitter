2. Before starting

  1. Auxiliaries ON (no red "Emergency" message).
  2. SONAR ON (green). If the popup "Sonar is OFF – turn it on?" appears, answer YES.
  3. Front gate down and side door closed.
  4. Check the speeds: VELOCITY (work) and FINAL VELOCITY (slow) potentiometers.
  5. AUTOMATIC VELOCITY CONTROL green.
  6. If the paper changed: answer the GSM question or press NEW GSM (§6).
  7. Set the T-one tension (TENSION HELPER, §7).

3. Threading the paper (JOG)

  • Hold the JOG button: the machine turns slowly (jog speed). Release = stop.
  • JOG is allowed with the front gate open (threading).
  • JOG is not allowed with the side door open (message "SIDE DOOR NOT CLOSED"). If the door opens during JOG, the machine stops.
  • JOG is blocked when the rewinder roll is too big (above "JOG MAX Ø").
  • After releasing JOG, START is ignored for 2 s.
  • No paper at the web break photocell: JOG still works (to thread), START does not.

4. Running: START, STOP, soft stop

START

  • Press START. The machine accelerates to the work speed with a smooth ramp.
  • START is refused (nothing moves) and a message tells why if: front gate open, side door open, no paper at the web break photocell, or an AUTO STOP target already reached.
  • With the tension check ON, the machine first turns slowly until the T-one reports tension, then accelerates (§7).

Emergency stop buttons: immediate stop of everything (red "Emergency" message). Release the button, restore the auxiliaries, press ALARMS RESET.

5. AUTO STOP (end of roll)

The machine can slow down and stop by itself at a metre count (unwinder) or at a rewinder diameter.

  1. Turn the AUTO STOP selector on the console ON → "AUTO STOP CONSOLE ACTIVE" (green).
  2. Enter the value while the AUTO button is still OFF:
    • Unwinder: STOP METRES (m) in the unwinder column.
    • Rewinder: STOP DIAMETER (mm) in the rewinder column.
  3. Press AUTO STOP UNWINDER or AUTO STOP REWINDER (yellow = armed, value locked). Only one at a time.
  4. Run normally. Near the target: horn beep, slow-down to the final speed, then a smooth stop exactly at the target.
  5. Message "AUTO STOP done" for a few seconds; one horn beep at standstill.
SituationWhat to do
Message "AUTO STOP refused – unwinder": metres already reachedReset the metre counter (eraser) or enter higher STOP METRES, then arm again.
Message "AUTO STOP refused – rewinder": roll already ≥ targetEnter a larger STOP DIAMETER or load a new core, then arm again.
AUTO STOP selector turned OFFBoth AUTO buttons switch OFF; the unwinder column shows the diameters again.
Without AUTO STOP, the unwinder still slows down and stops by itself at the minimum parent roll diameter (sonar ON), and the rewinder always stops at its maximum diameter (protection).

6. New roll / new paper (GSM)

  • After a new parent roll is loaded, the HMI asks "DIFFERENT GSM?":
    • YES = different paper → the machine forgets the learned thickness and learns it again.
    • NO = same paper → keeps the learned thickness.
  • NEW GSM button (hold 3 s): same as YES, at any time.
  • The thickness is learned automatically during the first metres of the roll ("GSM OK!" green, small value = thickness in mm). It is locked at 300 mm of rewinder diameter.
  • Rewinder new core: if the rewinder diameter reads wrong, ask the supervisor for "TEACH CORE" (§10).

7. Tension check (T-one) and Tension Helper

  • Set the T-one controller to the value shown (the T-one displays kg).
  • With START TENSION CHECK ON (RUN SETUP), after START the machine turns slowly until the T-one reports that the tension is established, then accelerates to the work speed. This avoids starting on a slack web.
  • If the tension is lost while running, the warning "Web tension too low / slack" appears (the machine does not stop). Check the paper path and the T-one.

9. Alarms and warnings – what to do

Alarm (red bar, buzzer pulses, lamp blinks): the cause must be removed. ALARMS RESET silences the buzzer for 1 minute and clears the alarm once the cause is gone.
Warning (blue bar, one short beep, lamp steady): information, the machine keeps going unless stated.

11. I/O status page (maintenance)

Questions or a repeated alarm: note the message, the time (shown in the bar) and what the machine was doing, then call the supervisor.
